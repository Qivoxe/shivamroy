Stochastic Control / Market Microstructure / Python & C++

Market-Making Simulator (Avellaneda–Stoikov)

An algorithmic market-making simulation engine built on the classic Avellaneda–Stoikov framework. Models high-frequency quoting strategies where an agent dynamically shifts bid and ask quotes away from the mid-price to manage inventory risk under Poisson arrival intensity.
